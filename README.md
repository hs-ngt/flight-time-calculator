# Flight Time Calculator

2地点の現地日時から時差と所要時間を算出するツールです。  
PHP / JavaScript / HTML / CSS / Bootstrap で作成。  
AIフル活用しています。  

## できること
- 出発地点 / 到着地点を検索付きで選択
- 出発日 / 出発時刻 / 到着日 / 到着時刻を入力
- 所要時間と時差を算出
- 出発 / 到着の入れ替え
- お気に入り地点を localStorage に保存
- 最近使った地点を localStorage に保存
- 直前入力を localStorage に保存
